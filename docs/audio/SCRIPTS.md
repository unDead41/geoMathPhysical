# Skrip bacaan GeoDecoder

Hanya isi dalam blok teks dibaca. ID dan label fail ialah rujukan pengurusan.
Sumber: `audio/elevenlabs/manifest.json`. Eksport dengan `python tools/question_audio.py --write`.

## P1

Soalan — `P1_soalan.mp3`

```text
Tapaknya berbentuk segi empat sama dan mempunyai empat muka berbentuk segi tiga. Bongkah apakah ini?
```

Hint — `P1_hint.mp3`

```text
Petunjuk: Bayangkan bentangannya dilipat. Muka sisi akan bertemu pada satu puncak.
```

## P2

Soalan — `P2_soalan.mp3`

Hint — `P2_hint.mp3`

```text
Petunjuk: Kuasa dua bagi panjang sisi tapak ialah luas tapak. Fikirkan bentuk muka sisi bongkah ini.
```
