|---|---|---|---|
| Isi command yang dijalankan | Host/emulator/telefon/staging | Pass/fail/blocked/not run | Fail/resit/hash |

## Pengesahan skop tindakan

Nyatakan tepat sama ada hanya fail disediakan, commit dibuat, branch dipush,
backend dipasang atau keluaran diterbitkan. Jangan menulis nombor SHA diri
sendiri dalam commit yang belum wujud atau mendakwa push sebagai deployment.
