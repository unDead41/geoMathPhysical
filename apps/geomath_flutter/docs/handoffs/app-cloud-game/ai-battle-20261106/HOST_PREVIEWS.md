Captured by an opt-in host-only scenario using actual production feature composition, controller, SQLite repository, math presenter and geometry card provider. Native preferences/secure storage/guest seams are host adapters; a controlled clock and seeds select reproducible states. Fonts use real Roboto and Material Icons, not Flutter's Ahem test font. Canvas 390 × 1300 dp, export 780 × 2600 px. These images are host widget renders, not Android screenshots. Displayed outcomes/times are controlled fixtures, not observed human win rates.
