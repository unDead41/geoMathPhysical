## Two existing protocols — preserve both inner formats

| Channel | Source and existing validation | Native integration implication |
|---|---|---|
| Progress `protocol:1` | `accessibility.mjs: ModuleAccess.init()/progress()` sends ready/progress; `guided.mjs: acceptModuleContext()` receives parent context | Context has `session`, effective light/dark theme, and progress; no owner/JWT |
| Parent progress | `digital/dist/module-progress.mjs: ModuleProgress.open()/close()/handleMessage()` checks active frame source, protocol, ready state, and per-open session | Session is a nonce generated by `createModuleSession()`; bind it to native actor/epoch outside JS |
| Preferences `version:1` | `module-frame.mjs: validateModuleSettings()/installModulePreferences()`; `module-settings.mjs: createModuleBridge()` checks opaque origin, source, channel, instanceId | Independent preferences instanceId; do not conflate it with progress session |

- `normalizeModuleRecord()` is the stricter parent boundary: only four activities
  `net/volume/area/composite`, four stages, Boolean completion, 240/600/600 text
  limits, trimming/control-character rejection and stage-required nonblank fields.
  Completed requires explanation stage. `mergeModuleProgress()` preserves earned
  completion against earlier milestones, but completed edits replace completed edits.
- `GuidedActivity` keeps earned record separate from live draft/check gates;
  `restore()` never unlocks observation/check. Projection/calculation are not
  additional formative activities. Native persistence must preserve this distinction.
- Preferences require `language(ms/en)`, `textSize(100/125/150)`, `motionPaused`;
  optional contrast, labels, autoRotate, resume, lastSection and audioEnabled are
  validated. `lastSection` only supports explore/notes/labs. Theme travels separately.

## Trust gaps to close after freeze

- Bare top-level WebView has `window.parent === window`; `ModuleAccess.embedded`
  is false and protocol-1 messages are not emitted. Existing iframe postMessage
  adapters are source evidence, not a working Flutter JavaScript-channel adapter.
- Neither inner protocol includes native actor/session scope/epoch or sequence.
  Apply a bounded, allowlisted native envelope without replacing the inner versions;
  validate current trusted document, module instance, nonce, actor binding and epoch
  before accepting writes or late asynchronous receipts. JS must not choose owner.
- Confirmed with real `ModuleProgress` source: replaying completed texts
  older→newer→older in the same session ends with older; an ignored 70000-character
  extra property is accepted. There is no global message byte cap or replay counter.
  Native needs a frozen size policy and replay handling; do not assume web merge
  deduplication supplies either. The planning 64 KiB cap is not a frozen signature.
- `createModuleBridge()` accepts only ready/open-settings/open-help/choice;
  choice is one allowed preference key. Preserve this allowlist, with no generic
  native RPC/evaluate-code operation and no credentials in the document/messages.
- Actor change must invalidate the previous document and pending callbacks.
  `digital/dist/app.mjs: openLearningModule()` already recreates the frame, with
  `moduleLaunchEpoch` and `moduleFrameActor` guards. A context-only swap is weaker:
  `app.mjs` clears guided answers and studios but leaves lab experiment/history
  objects; `labs.mjs: snapshot()/undo()` can retain old experimental state.
- `ModuleProgress._persist()` may retain memory after storage failure; this is not
  a native durable receipt. Save via frozen `FormativeRecordWriter`; use the matching
  Reader for records, surface EX11 on failure, and leave signed-in outbox to Prompt 3.

## Exact adapter seams and unresolved foundation contracts

- Host bootstrap: `prepareModuleFrame()` injects `installModulePreferences()`,
  language/copy/generated design CSS before module execution; it preserves document
  identity during settings sync. Its dependency closure is module-frame/language/
  copy/design, all under `digital/dist/`; do not silently omit translations/styles.
- `app.mjs: refreshModuleHost()` is the explicit presentation refresh hook via
  `window.__geodecoderModuleHost.start(...)`. Navigation/shape/lab entry points
  (`switchLearningView`, `selectShape`, `LearningLabs.openActivity`) are internal;
  native route control needs a deterministic pinned allowlisted adapter.
- Web visibility handlers stop speech, exploration rotation and lab frames;
  `LearningLabs.pause()/resume()` retains its timeline for deliberate resume.
  No durable camera/draft/checkpoint bridge exists. Native lifecycle/back, process
  death, single audio owner and actor-partitioned restoration remain unverified.
- Await real module-bridge/lifecycle/back APIs, ActorBinding, preferences DTO,
  FormativeRecordWriter/Reader receipts, database ownership, asset submanifest
  extension, contribution/preview entry points and Android WebView dependency pins.
  No substitute interfaces, storage, session, shell or scaffold are proposed here.
- Once READY is verified: record foundation/source hashes; export under learning
  ownership; hash bundle plus overlay in `assets/module/manifest.json`; implement
  the frozen ports; test corruption fallback, cold-start offline, actor/replay/
  lifecycle/storage failures and actual WebView; then run Flutter/device checks.
